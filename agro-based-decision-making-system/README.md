# Agro Based Decision Making System

Open `index.html` in a browser, or from this folder run:

```
python -m http.server 5500
```

Then visit http://localhost:5500

## Demo

1. **Login as Investor** → pick **Bihar** (other states listed, disabled) → product e.g. **Milk / Dairy** → district → subsidies, BERC FY 2026-27 tariffs, highway, water → **Hire workforce**.
2. **Login as Employer** → fill details → Technical / Non-technical → submit. Profile appears for investors in that district.
